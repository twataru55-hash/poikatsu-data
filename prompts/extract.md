- この取得元で使ってよい brand_ids: {{allowed_brand_ids}}
- 使ってよい store_ids: {{allowed_store_ids}}
- ページ本文:

# やること
ページ本文に書かれている、店頭での買い物に関係するキャンペーン・割引クーポン・無料引換券を、指定のJSON形式で書き出す。
詳細ページの主キャンペーンと、その条件表だけを対象にする。「関連・おすすめ・他のキャンペーン」のリンク見出しは別の候補にしない。別URLの詳細で確認する。

# 守ること
1. 本文に書かれていないことは書かない。わからない項目は null。
2. evidence_quote は本文から連続した文をそのまま抜き出す（最大200字）。言い換えない。還元率か期間が含まれる部分を選ぶ。
3. 期間の年が書かれていないときは今日の日付から判断する（例：今日が9月で「09/07〜10/25」なら今年）。今日から見て自然に1通りに決まれば、年が書かれていないことは unconfirmed の理由にしない。
3-2. confidence の決め方：還元内容と開始日・終了日がこのページ本文に書かれていれば "confirmed"。"unconfirmed" にするのは、本文に「予定」「詳細は後日」「決まり次第お知らせ」などとあり内容がまだ決まっていないとき、または年が1通りに決まらないときだけ。「予告なく変更・終了する場合があります」のような多くのページにある決まり文句は理由にしない。「ほかのページやブラウザで確かめていない」「自分で確認していない」ことは unconfirmed の理由にしない（確認は後の機械チェックが行う）。
3-3. 3-2 の例外：本文では特定の店だけが対象なのに、その店が「使ってよい store_ids」に無く payment_wide に置き換える場合は、元の対象店と対象限定を conditions に残し、confidence は "unconfirmed" にする。加盟店全体が対象だと確認できたことにはしない。保留の承認はしない。
4. 日時は "YYYY-MM-DDTHH:MM:SS+09:00" で書く。終了時刻が書かれていなければ 23:59:59、開始時刻が書かれていなければ 00:00:00。
5. ネット通販だけのキャンペーン、ポイントサイト、ふるさと納税、きせかえ・ギフト送付などお店での買い物と関係ないものは出さない。支払い方法やポイントカードの提示と関係なく「メーカー商品を買ってレシートで応募するだけ」のキャンペーンも出さない（支払い方法の指定があるものは出す）。
6. 還元率・上限・日付は本文の数字をそのまま使う。計算して作らない。rate_max は「%」の数字だけ（例 10）。倍率表記しかなければ null。
7. 改悪・終了・還元率の引き下げ・対象外化は type "change"。
8. 「最大」「抽選」などの条件語は rate_text に残す。rate_text は30字以内、title は40字以内、conditions は60字以内。
9. title・rate_text・conditions に「絶対」「必ず」「最強」「誰でも」「今すぐ」「損する」を入れない。
10. brand_ids と store_ids は、上の「使ってよい」リストの値だけを使う。当てはまる店がリストになければ scope.kind は "payment_wide"（その決済の加盟店全体）か "region"（自治体）にする。特定の店だけが対象の場合は 3-3 の対象限定・保留ルールを必ず適用する。
11. 自治体のキャンペーンは type "local"、scope.kind "region"、prefecture_codes に都道府県コード（北海道 "01" 〜 沖縄 "47"）を入れる。
12. official_url は取得元ページのURL（この依頼のURL）。エントリーの受付ページのURLが「ページ内のリンク」に載っていれば entry.url に入れる。アプリ内でエントリーするなどURLが無いときは entry.url は null でよい（entry.required は true のまま）。
13. 該当がなければ {"campaigns": []} を返す。
14. 店舗の値引き・無料引換券・クーポンは type "coupon"。本文が特定のポイント・決済利用を条件にしていなければ brand_ids は [] とし、scope.kind は "stores"、本文で確認できた対象店だけを指定する。共通ポイントを推測でひも付けない。割引額は rate_text に「対象商品20円引き」などそのまま書き、rate_max に金額や倍率を入れない。発券期間と利用期間が異なる場合は別々の期間・条件を混ぜず、利用できる期間と発券条件を明記する。個人ごとのアプリ限定・対象者限定・対象商品・地域限定を conditions に残す。本文に無い期限やエントリー不要を補わない。
15. 取得時点で終了済みのキャンペーン、商品発売のお知らせだけ、ポイント・割引・無料引換と関係のない景品だけの案内は出さない。常設で終了日時が示されていない有益な企画は null を保った候補として回答し、採用とは分ける。
